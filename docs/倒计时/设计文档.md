# 功能一：倒计时 · 设计文档

> 版本：v1.0
> 日期：2026-07-20
> 说明：基于已实现代码反向梳理倒计时功能的设计思路。公共基线见 `../项目总览.md`。

---

## 1. 用户场景

- 「距离高考还有多少天？」——预设节日/考试节点。
- 「女朋友生日还有多久？」——自定义 + 每年重复 + 农历。
- 「别忘记下周交材料」——到期前微信消息提醒。

---

## 2. 信息结构

倒计时项（card）包含：
- 名称、目标日期（公历/农历）、主题色
- 派生信息：剩余天数、星期、是否已过/今天、是否置顶、是否订阅
- 行为标记：`isPreset`（预置节日，不可删）、`repeat`（yearly 每年重复）、`isLunar`（农历）

---

## 3. 页面与交互

### 3.1 列表页（pages/countdown）
- 顶部三个 Tab：**全部 / 节日 / 我的**，切换即筛选。
- 排序规则：置顶优先 → 未过期按天数升序 → 已过期按天数降序。
- 右下角悬浮「+」进入添加页。
- 下拉刷新重新计算天数。

### 3.2 卡片交互（countdown-card 组件）
- 左滑（自定义项）露出删除；预置节日禁止删除。
- 长按弹出 ActionSheet：置顶 / 取消订阅提醒 / 删除。
- 铃铛图标快捷切换订阅。

### 3.3 添加页（pages/add）
- 表单：名称、日期类型（公历/农历切换）、目标日期、每年重复开关、订阅提醒开关、主题色（6 色）。
- 农历选择用独立月/日滚轮（支持闰月）。
- 实时预览卡片（天数、每年/农历徽标）。
- 保存后写入本地，若开启订阅则同步云数据库。

---

## 4. 订阅提醒（轻交互）

- 添加页或卡片上开启订阅 → 拉起微信订阅消息授权。
- 授权后云端记录 `notifyDays = [7, 3, 1, 0]`，即到期前 7/3/1 天及当天各提醒一次。
- 由云函数**定时触发器**（每日 08:00）扫描并发送订阅消息。

---

## 5. 视觉规范（倒计时）

| 用途 | 色值 |
| --- | --- |
| 主品牌色（倒计时 / 标题栏） | `#FF6B35` |
| 页面背景 | `#F8F6F3` |
| 卡片背景 | `#FFFFFF` |
| 次要文字 | 灰色 |

倒计时卡片支持 6 种主题色：活力橙、浪漫粉、天空蓝、清新绿、优雅紫、温暖黄。

组件风格：
- 列表卡片：细边框或极淡阴影，扁平。
- 按钮：圆角胶囊，主色填充或浅色描边。
- 标签/徽标：小圆角浅底。
