# 功能一：倒计时 · 开发文档

> 版本：v1.0
> 日期：2026-07-20
> 说明：基于已实现代码反向梳理倒计时功能的技术实现。公共基线见 `../项目总览.md`。

---

## 1. 数据模型

**自定义倒计时**（本地 `Storage` key = `custom_countdowns`）：
```js
{
  id: String,            // Date.now() 生成
  name: String,
  date: 'YYYY-MM-DD',    // 公历有效日期
  color: String,         // 主题色
  repeat: 'none' | 'yearly',
  isLunar: Boolean,
  lunarMonth: Number,
  lunarDay: Number,
  isLeapMonth: Boolean,
  isPreset: false
}
```

**预置节日**（`utils/holiday.js` 提供，按年生成，含农历春节等）。

**置顶记录**（本地 `Storage` key = `pinned_ids`，存 `name` 或 `id` 数组）。

**云端订阅**（`subscriptions` 集合，见 4）。

---

## 2. 核心计算（`utils/util.js`）

| 函数 | 职责 |
| --- | --- |
| `daysUntil(dateStr)` | 目标日与今天天数差（未来正/已过负/今天 0） |
| `formatDateCN` / `getWeekDay` | 中文日期 / 星期 |
| `resolveRepeatDate(item)` | 解析 yearly/农历事件的「下一次」有效日期 |
| `formatLunarDateCN` | 农历日期中文（依赖 `lunar.js`） |
| `loadCustomCountdowns` / `addCustomCountdown` / `removeCustomCountdown` | 本地 CRUD |
| `loadPinnedIds` / `togglePin` | 置顶切换 |
| `mergeAndSort` | 合并预置与自定义并按规则排序 |

排序规则：置顶优先 → 未过期升序 → 已过期降序。

---

## 3. 列表页与卡片组件

- `pages/countdown/countdown.js`：
  - `onShow` 重新加载（保证从添加页返回后刷新）。
  - `loadData` 合并预置节日与自定义，调用 `loadSubscriptions()` 拉取云端订阅态。
  - Tab 切换仅改变 `activeTab`，由 `getCurrentList()` 返回对应数组。
- `components/countdown-card`：
  - `properties.item` 接收单项。
  - 左滑（`onTouchMove` deltaX < -30）显示删除；预置项 `isPreset` 禁止滑动删除。
  - 长按 `onLongPress` → `wx.showActionSheet`（置顶 / 订阅 / 删除）。
  - 通过 `triggerEvent` 向上派发 `delete` / `pin` / `subscribe` / `tap`。

## 4. 添加页（`pages/add`）

- 日期类型切换：`solar`（原生 `picker mode=date`）/ `lunar`（自实现月/日 selector，依赖 `lunar.js` 的 `getLunarMonthList` / `getLunarDayList`）。
- 农历→公历转换在 `getEffectiveDate()` 中完成，存入 `date` 字段（始终为公历 YYYY-MM-DD）。
- `onSave` → `addCustomCountdown` 写本地；若 `subscribed` 为真且 `wx.cloud` 就绪，调用 `addCloudSubscription` 写云库。

## 5. 云函数 `subscribe`

入口 `exports.main` 按 `action` 分发：

| action | 说明 |
| --- | --- |
| `add` | 写入 `subscriptions`（带 `_openid`，去重） |
| `remove` | 按 `itemId` 删除 |
| `list` | 列出当前用户订阅 |
| `send` | 扫描全库，命中 `notifyDays` 且当日未发则下发订阅消息 |
| `test` | 发送一条测试消息（联调用） |

- 发送逻辑 `sendSubscribeMessage` 直接调用微信 HTTP API（自管 `access_token` 缓存）。
- 模板字段：`thing01`(剩余) / `time01`(日期) / `thing02`(名称) / `thing03`(备注)。
- **定时触发**：`config.json` 中 `triggers` 配置 `0 8 * * * * *`（每日 08:00，云开发定时器语法）。
