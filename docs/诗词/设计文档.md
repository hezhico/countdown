# 功能二：诗词 · 设计文档

> 版本：v1.0
> 日期：2026-07-20
> 说明：基于已实现代码反向梳理诗词功能的设计思路。公共基线见 `../项目总览.md`。

---

## 1. 用户场景

- 通勤碎片时间读一首唐诗。
- 想看繁体版本（如书法、古籍语境）。
- 夜间护眼阅读 / 调大字号。
- 随机来一首，或按类别精读。

---

## 2. 阅读器设计

全屏沉浸式，主题三选一：
- **日间**（米白底深字）
- **护眼**（泛黄宣纸底）
- **夜间**（深底浅字）

正文居中排版，标题/作者/正文层次分明；支持**字号四档**循环（34/40/46/52 rpx）。

---

## 3. 列表与检索

- 顶部分类标签横向滚动：唐诗、宋词、诗经、楚辞、纳兰词、曹操诗、水墨唐诗、幽梦影、论语、蒙学。
- 搜索栏支持按**标题/作者**模糊搜索。
- 「随机」按钮内嵌搜索栏，一键随机一首并进入阅读器。
- 繁简切换（简/繁）内嵌搜索栏。

---

## 4. 阅读器导航

- 底部栏：**上一首 / 进度（x/N） / 下一首**。
- 正文区**左右滑动**切换上一首/下一首。
- 顶部完全交给**系统导航栏**返回，不叠加自定义栏，避免与标题重叠。

---

## 5. 浮动扇形设置按钮（核心交互）

- 阅读器右下偏上放置一个 **⚙ 设置按钮**。
- 点击后**扇形展开**两个功能点：
  - **阅读模式**（🌞/📜/🌙 循环切换主题）
  - **字号**（Aa 循环切换四档）
- 展开时主按钮旋转 45°；点击任一功能即生效并自动收起。
- 设计意图：把低频设置折叠，保持阅读界面纯净，同时保证单手可达。

```
        🌞 主题
       ╱
   ⚙ ──┼──（收起时重叠于主按钮中心）
       ╲
        Aa 字号
```

---

## 6. 视觉规范（诗词）

| 用途 | 色值 |
| --- | --- |
| 诗词主题色 | 紫 `#6A5ACD` → `#9D8DF1` |
| 页面背景 | `#F8F6F3` |
| 卡片背景 | `#FFFFFF` |
| 次要文字 | 灰色（依主题动态） |

组件风格：
- 列表卡片：细边框或极淡阴影，扁平。
- 按钮：圆角胶囊，主色填充或浅色描边。
- 标签/徽标：小圆角浅底。
