# 功能三：汉字拼音 · 设计文档

> 版本：v2.0
> 日期：2026-07-22
> 说明：新增「汉字拼音」学习功能的设计思路。公共基线见 `../项目总览.md`，数据/实现细节见 `开发文档.md`。

---

## 1. 用户场景

- 小学生或拼音初学者，利用碎片时间逐字记忆汉字与拼音。
- 家长陪孩子复习：翻看汉字，核对拼音、声调、部首与组词。
- 自检闯关：看汉字选出正确拼音，查漏补缺、巩固记忆。
- 按**声母**分组浏览字表，归纳拼音规律（b / p / m / f … zh / ch / sh / r … y / w / 零声母）。
- 纯离线、无语音，弱网/无网可用。

---

## 2. 三种学习模式

页面顶部为分段控件（胶囊 tab），切换：`浏览 / 卡片 / 测验`，三者共享同一份字库。

### 2.1 浏览模式（字词浏览）

- **声母分类**横向滚动 tab（B / P / M / F / D / T / N / L / G / K / H / J / Q / X / ZH / CH / SH / R / Z / C / S / Y / W / 零声母，共 24 组）。
- 字词卡片列表：左为大号汉字，右侧为拼音（带声调小字）+ 释义预览。
- 点击卡片展开「详情」：拼音（带声调）、声调数字（1–4 / 轻声）、**部首、笔画数**、释义、组词 chips。
- 搜索栏支持按汉字 / 拼音 / 释义模糊检索（跨声母）。

### 2.2 卡片翻翻看（记忆卡）

- 居中大翻转卡：正面超大汉字（约 160rpx），背面拼音（带声调、大号）+ 释义。
- 点击卡片触发 **3D 翻转**（`transform: rotateY` + 250ms 缓动），正反面切换。
- 底部操作：`上一张 / 随机 / 下一张`，并显示进度 `x / y`。
- 翻面状态由 `flipped` 布尔控制，仅切换类名，避免整页重渲。

### 2.3 测验闯关（四选一）

- 居中题目汉字（大号），下方四个拼音选项卡片（2×2 网格）。
- 干扰项生成优先取「同声调 / 同声母」的其他字拼音，提升区分度；不足时退回随机拼音，最终 4 项唯一并打乱顺序。
- 点击选项即时反馈：选对绿色 `#52C41A`、选错红色 `#FF4D4F`，并展示正确拼音；伴随短震动 `wx.vibrateShort`。
- 顶部显示当前得分与进度；「下一题」继续，可重开。

## 3. 信息架构

```
百宝箱（首页 / 功能入口网格）
├── 倒计时  →  pages/countdown
├── 诗词    →  pages/poetry
└── 汉字拼音 →  pages/hanzi   （浏览 + 卡片 + 测验，单页三模式）
```

- 首页只做分发；汉字拼音为独立二级页，使用**系统导航栏**（自带返回）。
- 三模式在同一页面内通过 `mode` 状态切换，不拆分多页，避免字库重复加载。

## 4. 视觉规范（汉字拼音）

| 用途 | 色值 |
| --- | --- |
| 主题色（渐变） | 橙 `#FF6B35` → `#FF8C42` → `#FFA559` |
| 页面背景 | `#F8F6F3` / `#FFFFFF` |
| 主要文字 | `#2D2D2D` |
| 次要文字 | `#666666` |
| 提示文字 | `#999999` |
| 正确 / 错误 | `#52C41A` / `#FF4D4F` |

组件风格（与现有功能保持一致）：

- 标题区：橙色扁平背景、白字，与首页 `header` 同款。
- 分段控件：三个胶囊 tab，选中态橙色填充白字，未选浅灰底。
- 卡片 / 选项：白色圆角卡片，柔和阴影（`--shadow-card`），扁平克制。
- 组词 / 标签：小圆角浅底 chip；详情中的部首/笔画用浅灰 chip。
- 动效：翻卡 3D 旋转、模式/tab 切换 150ms 过渡，轻盈不喧宾夺主。
- 适配：基于 `rpx`，底部 `.safe-bottom` 安全区。

## 5. 字库数据说明

- 内置「小学常用字」数据集，**按字频取最常用的 3000 字**，再按**声母**分为 24 组（含零声母），离线可用。
- 每条字数据形态：
  ```js
  {
    char: '一', pinyin: 'yī', tone: 1,
    meaning: '（指事。“一”是汉字部首之一。本义:数词…）',
    words: ['一丁', '一七', …],     // 组词（取自字典，数量不一）
    radicals: '一',                  // 部首
    strokes: 1                       // 笔画数
  }
  ```
- 拼音带正确声调标调（`yī` / `hǎo`），`tone` 为 1–4 数字，轻声为 `0`，供测验与展示使用。
- **数据来源**（构建期，非运行时依赖）：
  - `char_base.json`：汉字拼音（带声调）、部首、笔画、字频。
  - `char_common_detail.json`：释义与组词。
  - 拼音由 `pinyin-pro` 取最常用读音，确保多音字准确。
- 生成脚本：`utils/hanzi_data/_gen/build.js`，由上述两份数据源构建 `utils/hanzi_data/common.js`。后续扩展字库只需重跑脚本或手工编辑 `common.js`。
