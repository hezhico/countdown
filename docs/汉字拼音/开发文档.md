## 1. 数据层（`utils/hanzi.js` + `utils/hanzi_data/common.js`）

- 数据集以 `.js` 模块导出，存放于 `utils/hanzi_data/` 子目录（纯英文路径，绕开小程序 `require` 中文路径限制）。
- `common.js` 导出结构：
  ```js
  module.exports = {
    categories: [
      {
        key: 'b',                 // 声母（零声母为 'zero'）
        name: 'B',                // 分类展示名（'零声母' 等）
        chars: [
          {
            char: '八', pinyin: 'bā', tone: 1,
            meaning: '（象形。甲骨文象分开相背的样子…）',
            words: ['八成', '八方', …],
            radicals: '八', strokes: 2
          }
          // …更多字
        ]
      }
      // …其余声母组（共 24 组）
    ]
  }
  ```
- 加载器 `utils/hanzi.js` 暴露以下接口：
  - `getCategories()` → `[{ key, name, count }]`，供浏览模式 tab 使用（按声母排序）。
  - `getChars(key)` → 该声母组 `chars` 数组。
  - `getAllChars()` → 跨组扁平化全部字（测验/随机用）。
  - `getRandom(n)` → 跨组随机取 `n` 个字。
  - `search(kw)` → 按汉字 / 拼音 / 释义 `indexOf` 模糊检索，跨组返回。
  - `genOptions(char)` → 返回 `[{ text, correct }]` 共 4 项，含 1 正确 + 3 干扰，已打乱顺序。
- `genOptions` 干扰项策略：优先从「同 `tone`」或「同声母」的其他字拼音中挑选 3 个（提升区分度），不足时退回随机其他拼音；最终保证 4 选项文本唯一后用 Fisher–Yates 打乱。

## 2. 页面（`pages/hanzi`）

### 2.1 数据结构（`data`）

```js
{
  mode: 'browse',          // 'browse' | 'card' | 'quiz'
  categories: [],          // 声母分类
  activeKey: 'b',          // 当前浏览声母组（默认首组）
  chars: [],               // 当前组字列表
  keyword: '',
  filtered: [],            // 浏览检索结果
  showDetail: false,
  detail: null,            // 浏览详情字（含 radicals / strokes）
  // 卡片模式
  cardIndex: 0,
  flipped: false,
  cardTotal: 0,
  // 测验模式
  quizCurrent: null,       // 当前题目字
  quizOptions: [],         // [{text, correct}]
  quizSelected: -1,        // 选中项下标，-1 未答
  quizAnswered: false,
  quizScore: 0,
  quizDone: 0,
  quizTotal: 0
}
```

### 2.2 生命周期与公共

- `onLoad`：读取 `getCategories()` 赋 `categories`，默认 `browse` 模式并加载首个声母组 `loadCategory(key)`。
- `onSwitchMode(e)`：切换 `mode`；进入 `card` 调 `startCard()`，进入 `quiz` 调 `startQuiz()`。

### 2.3 浏览模式

- `loadCategory(key)`：取该声母组字赋 `chars` / `filtered`，`keyword` 清空。
- `onCategoryTap`：切换 `activeKey` 并重载。
- `onSearch`：按汉字/拼音/释义过滤 `chars` → `filtered`。
- `openDetail(e)` / `closeDetail`：展开/收起某字详情（`detail`），详情含 `radicals` / `strokes` 展示。

### 2.4 卡片模式

- `startCard()`：从 `getAllChars()` 取全量字，`cardIndex=0`、`flipped=false`。
- `onCardTap`：翻转 `flipped`。
- `onCardPrev` / `onCardNext`：在 `[0, cardTotal)` 循环切换，重置 `flipped=false`。
- `onCardRandom`：随机下标，重置 `flipped=false`。

### 2.5 测验模式

- `startQuiz(n=10)`：`quizTotal=n`，重置得分/进度，调 `nextQuiz()`。
- `nextQuiz()`：从 `getRandom(1)` 取题，`genOptions` 生成选项，`quizSelected=-1`、`quizAnswered=false`。
- `onQuizOption(e)`：记录选中下标、标记已答；若该项正确 `quizScore++`；`quizDone++`；`wx.vibrateShort()` 反馈。
- 反馈样式：选对绿色 `--正确色`，选错红色 `--错误色`，并展示正确拼音。

## 3. 样式（`pages/hanzi/hanzi.wxss`）

- 复用 `app.wxss` 全局变量（`--bg-page` / `--bg-card` / `--text-*` / `--radius-*` / `--shadow-card`）。
- 翻卡 3D：
  ```css
  .flip-card { perspective: 1000rpx; }
  .flip-inner { transition: transform .25s; transform-style: preserve-3d; }
  .flip-inner.flipped { transform: rotateY(180deg); }
  .flip-front, .flip-back { backface-visibility: hidden; position: absolute; }
  .flip-back { transform: rotateY(180deg); }
  ```
- 选项反馈：`option-correct` 绿底、`option-wrong` 红底，过渡 150ms。
- 详情新增 `.detail-info` / `.info-chip`：展示部首、笔画数（浅灰圆角 chip）。
- 分段控件 / 声母 tab 复用 `.cat-scroll` 视觉语言；底部 `.safe-bottom` 安全区。

- `app.json` 的 `pages` 数组追加 `"pages/hanzi/hanzi"`。
- `pages/index/index.js` 的 `features` 数组追加入口：
  ```js
  {
    id: 'hanzi',
    name: '汉字拼音',
    desc: '翻卡测验，轻松记拼音',
    icon: '🔤',
    bg: 'linear-gradient(135deg, #FF6B35, #FFA559)',
    url: '/pages/hanzi/hanzi'
  }
  ```
- 新增功能与 poetry 同理，无需改动首页布局。

## 5. 注意事项

1. 数据集拼音须带正确声调标调，避免同音字歧义（如 `yī` / `yí` / `yǐ` / `yì`）；轻声记为 `tone: 0`。
2. 字库共 3000 字一次性 `require` 进内存（约数百 KB），`getChars/search/genOptions` 均为 O(n) 内简单遍历，无网络与渲染瓶颈。
3. 测验计分存于页面 `data`（本会话内），不强制持久化；如需记忆可用 `wx.setStorageSync`（本期不做）。
4. 可扩展性：扩展字库只需编辑 `utils/hanzi_data/common.js`（或重跑 `utils/hanzi_data/_gen/build.js`）。`utils/hanzi.js` 与页面逻辑均按 `categories` 泛型处理，无需改动。
5. 构建依赖（`pinyin-pro`、原始字典 JSON）仅用于生成 `common.js`，运行时**不依赖** `_gen/` 与 `node_modules`；发布前可删除 `utils/hanzi_data/_gen/`。
