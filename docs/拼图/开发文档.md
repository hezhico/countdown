## 3. 数据结构（`puzzle.js`）

```js
data: {
  layout: 4,            // 当前版式：2 / 4 / 9（格子数）
  layouts: [2, 4, 9],   // 三档
  photos: [],           // 已选照片临时路径数组（长度需 == layout）
  cells: [],            // 渲染用：每格 { src, index }，index 指向 photos
  dragging: -1,         // 正在拖动的格子下标，-1 表示无
  dragX: 0, dragY: 0,   // 拖动浮层位置（px）
  gap: 8,               // 格子间隙 rpx
  output: 1080          // 输出正方形边长 px
}
```

- `photos` 存 `wx.chooseMedia` 返回的真实路径；`cells` 仅记录排列顺序（拖动用 cells 换位，不直接动 photos）。
- 顺序与照片解耦：拖动交换 `cells[i]` 与 `cells[j]` 的 `index` 即可，无需移动照片文件。

## 4. 选图（`wx.chooseMedia`）

```js
choosePhotos() {
  const n = this.data.layout
  wx.chooseMedia({
    count: n,
    mediaType: ['image'],
    sourceType: ['album', 'camera'],
    sizeType: ['compressed'],
    success: (res) => {
      const photos = res.tempFiles.map(f => f.tempFilePath)
      if (photos.length < n) {
        wx.showToast({ title: `需选 ${n} 张`, icon: 'none' }); return
      }
      const cells = photos.map((src, i) => ({ src, index: i }))
      this.setData({ photos, cells })
    }
  })
}
```

- 选图数量不足版式所需：提示并停留，不覆盖已有 `cells`。
- 切版式时：若已选图数量与新手数不符，清空并重选（或提示重选）。

## 5. 版式引擎（网格与 cover 裁切）

- 网格按 `layout` 计算行列：2→1×2，4→2×2，9→3×3。
- 界面格子用 CSS Grid / flex 均分，正方形单元格。
- 合成时 cover 计算（以目标矩形 `dw×dh`、图片原始 `iw×ih`）：

```js
function coverRect(iw, ih, dw, dh) {
  const scale = Math.max(dw / iw, dh / ih)
  const sw = iw * scale, sh = ih * scale
  return { sx: (sw - dw) / 2 / scale, sy: (sh - dh) / 2 / scale,
           sw: dw / scale, sh: dh / scale }
}
// drawImage(img, sx, sy, sw, sh, dx, dy, dw, dh)
```

## 6. 自由拖动换位（touch 事件）

- 每个格子 `bindtouchstart` / `bindtouchmove` / `bindtouchend`，带 `data-idx`。
- `touchstart`：启动 200ms 计时器进入拖动态，记录起始格 `dragging`。
- `touchmove`：更新浮层 `dragX/dragY` 跟随手指；根据触摸坐标命中哪个格子计算 `targetIdx`，高亮目标格。
- `touchend`：若 `targetIdx` 有效且 ≠ `dragging`，交换 `cells[dragging]` 与 `cells[targetIdx]` 的 `index`；重置 `dragging=-1`。

```js
onTouchEnd(e) {
  const from = this.data.dragging, to = this.data.targetIdx
  if (from >= 0 && to >= 0 && from !== to) {
    const cells = this.data.cells.slice()
    const t = cells[from].index; cells[from].index = cells[to].index; cells[to].index = t
    this.setData({ cells, dragging: -1, targetIdx: -1 })
  } else {
    this.setData({ dragging: -1, targetIdx: -1 })
  }
}
```

- 兜底：未进入拖动态时，`touchstart` 直接 `touchend` 判定为「点选」——记录第一次点选格，第二次点选时交换（点击换位）。

## 7. Canvas 合成与导出

```js
async compose() {
  const dpr = wx.getWindowInfo().pixelRatio || 2
  const size = this.data.output * dpr
  const canvas = await this.getCanvas()         // SelectorQuery 取 canvas node
  const ctx = canvas.getContext('2d')
  // 先量取屏幕上棋盘的真实尺寸（boundingClientRect），做到所见即所得
  const rect = await getBoardRect()
  const scaleUp = 1080 / Math.max(rect.width, rect.height)  // 长边固定 1080
  const bw = Math.round(rect.width * scaleUp)
  const bh = Math.round(rect.height * scaleUp)
  const gap = this.data.gap * scaleUp
  const cell = this.data.cellPx * scaleUp
  const radius = (12 * info.windowWidth / 750) * scaleUp    // 与屏幕 .cell 的 12rpx 圆角一致

  canvas.width = bw; canvas.height = bh
  ctx.fillStyle = '#FFFFFF'; ctx.fillRect(0, 0, bw, bh)      // 白底

  const n = this.data.layout
  const cols = n === 2 ? 2 : Math.sqrt(n)
  for (let i = 0; i < n; i++) {
    const r = Math.floor(i / cols), c = i % cols
    const dx = gap + c * (cell + gap), dy = gap + r * (cell + gap)
    const img = await this.loadImage(this.data.photos[this.data.order[i]])
    ctx.save(); roundRect(ctx, dx, dy, cell, cell, radius); ctx.clip()  // 圆角裁切
    const { sx, sy, sw, sh } = coverRect(img.width, img.height, cell, cell)
    ctx.drawImage(img, sx, sy, sw, sh, dx, dy, cell, cell)
    ctx.restore()
  }
  wx.canvasToTempFilePath({ canvas, success: (r) => this.save(r.tempFilePath) })
}

save(path) {
  wx.saveImageToPhotosAlbum({
    filePath: path,
    success: () => wx.showToast({ title: '已保存到相册' }),
    fail: (err) => {
      if (/auth deny|authorize/.test(err.errMsg))
        wx.showModal({ title: '需要相册权限', content: '请在设置中开启',
          success: (m) => { if (m.confirm) wx.openSetting() } })
      else wx.showToast({ title: '保存失败', icon: 'none' })
    }
  })
}
```

- `getCanvas`：用 `wx.createSelectorQuery().select('#compose').fields({ node: true, size: true })` 取 2d canvas。
- `loadImage`：`new Promise((res) => { const img = canvas.createImage(); img.src = p; img.onload = () => res(img) })`。

## 8. 权限与异常处理

- 相册写入：`scope.writePhotosAlbum`；首次保存触发授权弹窗，拒绝后走 `wx.openSetting` 引导。
- 选图取消：不改动 `cells`。
- 数量不符：选图成功但 `< n` 时提示「需选 N 张」并重选。
- 大图：选图用 `compressed`；Canvas 按 `output*dpr` 上限绘制，避免内存爆掉。

## 9. 实现结论（已确认）

1. **拖动**：网格内拖拽换位（长按拖动 → 落点格交换），非自由画布。
2. **版式**：仅 2/4/9 规则网格，三档切换。
3. **间隙**：固定白色细间隙。
4. **导出**：`saveImageToPhotosAlbum` 保存相册 + `wx.showShareImageMenu` 转发好友，两者均提供。
5. **输出**：所见即所得——按屏幕棋盘实际比例输出，长边固定 1080；白边间隙比例、12rpx 圆角均与屏幕一致，不再写死正方形（2 格等横向版式也能正确出图）。

> 实现以此为基准。
