# 功能四：拼图 · 设计文档

> 版本：v1.0
> 日期：2026-07-31
> 说明：新增「拼图」功能的设计思路。公共基线见 `../项目总览.md`。本文为先行设计稿，开发前请确认「开放问题」一节。

---

## 1. 用户场景

- 想把几张照片拼成一张长图，发朋友圈 / 微信群。
- 旅游拍了一组图，挑 2~9 张拼成一张方图分享。
- 不想装额外的拼图 App，在「百宝箱」里随手拼好就存相册。

设计目标延续百宝箱基调：**入口统一、使用素净、离线可用、扩展容易**。拼图不依赖云端，纯前端相册 + Canvas 合成。

---

## 2. 功能定义

「拼图」= **图片拼接（多图合成）**：用户从相册选取多张照片，套用一种网格版式把它们拼成**一张**方图，调好顺序后一键保存到相册。

- 不是拼图游戏（复原单张图），也不是滑块华容道。
- 成品是一张静态图片，用途是**分享 / 留存**。

---

## 3. 核心流程

```
进入拼图页
  → 选择版式（2 格 / 4 格 / 9 格 三档）
  → 调起相册选对应数量的照片（wx.chooseMedia）
  → 编辑：拖动照片在格子间换位（自由拖动）
  → 一键生成：Canvas 合成 → 保存到相册
  → 可「重新选图 / 换版式 / 再拼一张」
```

> 备选顺序（实现时若更顺手可改为）：先多选照片（1~9 张），再选版式，版式中格数大于已选数量的档位置灰并提示「需选 N 张」。两种顺序均可行，文档以「先选版式」为主描述。

---

## 4. 版式三档

| 档位 | 网格 | 所需照片数 | 说明 |
| --- | --- | --- | --- |
| 简约（2 格） | 1×2 横排（默认） | 2 | 左右两张并排，方图 |
| 经典（4 格） | 2×2 | 4 | 四宫格 |
| 九宫（9 格） | 3×3 | 9 | 朋友圈经典九宫格 |

- 输出图统一为**正方形**（如 1080×1080，按设备 dpr 放大绘制保证清晰）。
- 格子之间留**白色间隙**（gap），整体留白边，呈现素净拼图观感。
- 每格内照片以 **cover（等比填满、居中裁切）** 方式绘制，避免拉伸变形。

> 开放问题：是否要支持「竖排 2×1」「不规则模板（品字 / 一大两小）」等更多模板？v1 先按规则网格（2/4/9）实现，不规则模板作为后续增强。

---

## 5. 自由拖动交互（换位）

还原交互按你的选择为 **自由拖动**：在选定版式后，可**长按某张照片并拖动，放到另一个格子上即交换两者位置**，让用户自由决定哪张照片在哪个格子。

- 交互模型：**拖拽换位（drag-to-swap）**，不是自由画布任意摆放、也不是缩放旋转。
- 触发：长按单元格 ~200ms 进入「拖动态」，被拖照片浮起（轻微放大 + 阴影）。
- 跟随：拖动过程中照片跟随手指（或显示占位高亮目标格）。
- 落点：手指松开时，根据落点坐标判断目标格子；与目标格的照片**互换数据位置**并刷新。
- 边界：松开在空白/原格则归位不交换。
- 辅助：除拖动外，也允许「点选两张依次点击交换」作为兜底（无障碍 / 误触友好），但主交互是拖动。

> 开放问题：「自由拖动」是否有其它意图（例如自由画布任意摆放+缩放）？本设计按「网格内拖拽换位」理解。若需自由画布，请告知，设计需整体调整。

---

## 6. 生成与导出

- 合成：用 `canvas`（`type="2d"`）按输出尺寸绘制——先铺白底，再逐格 `drawImage` 以 cover 方式绘制对应照片。
- 导出：`canvas.toTempFilePath` 得到临时图片路径。
- 保存：`wx.saveImageToPhotosAlbum`（需 `scope.writePhotosAlbum` 授权）。
- 授权拒绝：引导用户去「设置」页开启相册权限（`wx.openSetting`）。
- 完成反馈：保存成功后 `wx.showToast` 提示「已保存到相册」。

---

## 7. 视觉规范（拼图）

| 用途 | 色值 |
| --- | --- |
| 拼图主题色 | 橙 `#FF6B35` → `#FFA559`（与倒计时/汉字同色系，保持百宝箱一致） |
| 页面背景 | `#F8F6F3` |
| 卡片/格子背景 | `#FFFFFF` |
| 间隙 / 描边 | 白色间隙 + 极淡灰边 |

组件风格（与既有功能一致）：
- 版式选择卡：圆角卡片，选中态主色描边 / 高亮。
- 按钮：圆角胶囊，主色填充。
- 格子：圆角小、扁平、白间隙。

---

## 8. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 选图数量不足版式所需 | 版位置灰并提示「需选 N 张」；或允许重复用同一张补足（v1 采用置灰提示） |
| 用户取消选图 | 回到版式选择，不做任何变更 |
| 相册授权被拒 | 引导 `wx.openSetting` 开启；不阻塞浏览，仅阻止保存 |
| 保存失败（磁盘满 / 权限） | `showToast` 错误原因 |
| 图片过大 | `chooseMedia` 设 `sizeType:['compressed']` 控制体积；Canvas 按 dpr 上限绘制 |
| 极端比例照片 | cover 裁切保证不出框、不变形 |

---

## 9. 设计结论（已确认）

| 议题 | 结论 |
| --- | --- |
| 拖动语义 | **网格内拖拽换位**：长按拖动照片到目标格即交换（已确认，非自由画布） |
| 版式范围 | **仅 2/4/9 规则网格**（已确认，暂不做竖排 / 不规则模板） |
| 间隙白边 | 固定白色细间隙（v1 默认，背景色切换留待增强） |
| 导出方式 | **两者都要**：可保存到相册（`saveImageToPhotosAlbum`），也可转发给好友（`showShareImageMenu`） |
| 输出尺寸 | 默认正方形 1080×1080（按 dpr 放大绘制） |

> 其余细节按本设计默认实现，可直接试用后反馈微调。
