# 百宝箱小程序 · 项目总览

> 版本：v2.0
> 日期：2026-07-22
> 说明：本文档为跨功能公共基线（产品定位、技术栈、目录、部署等）。各功能的设计与开发细节见 `倒计时/`、`诗词/`、`汉字拼音/` 子目录文档。

---

## 1. 产品定位

「百宝箱」是一个**轻量工具聚合型小程序**。首期内置四个高频小工具：

- **倒计时**：记录重要时刻（考试、生日、纪念日、节日），支持农历、每年重复、到期提醒。
- **诗词**：离线赏析经典诗词文赋，支持繁简切换、阅读主题与字号调节。
- **汉字拼音**：内置小学常用字库，提供浏览、卡片翻翻看、测验闯关三种模式，离线记忆汉字与拼音。
- **拼图**：从相册选取多张照片，套用网格版式（2/4/9 格）拼成一张方图，拖动换位后一键保存到相册，用于分享。

设计核心目标：**把常用小工具收进一处，入口统一、使用素净、扩展容易**。

---

## 2. 设计原则

| 原则 | 说明 |
| --- | --- |
| 素净克制 | 首页去开场动画、去重阴影，二级页去掉自定义导航栏改用系统栏，减少视觉噪音 |
| 入口统一 | 首页即「功能入口网格」，新增功能只需追加一条配置，无需改动布局 |
| 单手优先 | 阅读器设置按钮置于右下偏上，扇形展开，拇指可达 |
| 可离线 | 诗词数据本地内置，倒计时数据本地存储，弱网/无网可用 |
| 适度云端 | 仅「订阅提醒」依赖云开发（云函数 + 数据库 + 定时触发器） |

---

## 3. 信息架构

```
百宝箱（首页 / 功能入口网格）
├── 倒计时  →  pages/countdown  （列表 + Tab + 添加）
│             └── 添加  →  pages/add
├── 诗词    →  pages/poetry    （分类 + 搜索 + 阅读器）
└── 汉字拼音 →  pages/hanzi     （浏览 + 卡片翻翻看 + 测验闯关，单页三模式）
└── 拼图     →  pages/puzzle    （选图 + 版式 + 拖动换位 + 合成保存，纯前端）
```

- 首页只做**分发**，不承载具体功能逻辑。
- 所有二级页使用**系统导航栏**（自带返回箭头），降低开发复杂度、保证返回一致。
- 阅读器为**全屏沉浸式覆盖层**，覆盖在诗词列表之上，关闭即回到列表。

## 4. 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | 微信小程序原生（WXML / WXSS / JS），无框架 |
| 包管理 | 小程序原生 `app.json` 路由，组件化 `Component` |
| 本地存储 | `wx.getStorageSync` / `setStorageSync` |
| 云端能力 | 微信云开发（云函数 + 云数据库 + 定时触发器） |
| 订阅消息 | 微信订阅消息 `wx.requestSubscribeMessage` + 云函数主动下发 |

## 6. 路由与导航

`app.json` 中注册页面（首页即启动页）：

```json
"pages": [
  "pages/index/index",
  "pages/countdown/countdown",
  "pages/add/add",
  "pages/poetry/poetry",
  "pages/hanzi/hanzi",
  "pages/puzzle/puzzle"
]
```

- 首页 → 二级页：`wx.navigateTo`（保留返回栈）。
- 阅读器：在 `pages/poetry` 内以 `wx:if` 条件渲染的全屏 `fixed` 覆盖层，非独立页面。
- 所有二级页 `navigationStyle` 为**默认系统导航栏**（自带返回），未启用自定义导航栏。

## 7. 全局样式（`app.wxss`）

CSS 变量（页面复用）：

## 8. 部署与配置

1. **云开发环境**：在微信开发者工具开通云开发，记录环境 ID。
2. **部署云函数**：右键 `cloudfunctions/subscribe` → 上传并部署（含 `node_modules` 或云端安装依赖）。
3. **数据库**：创建集合 `subscriptions`，权限设为「仅创建者可读写」或按业务调整。
4. **订阅消息模板**：在微信公众平台申请模板，将模板 ID 同步到：
   - `pages/countdown/countdown.js` 的 `SUBSCRIBE_TEMPLATE_ID`
   - `pages/add/add.js` 的 `SUBSCRIBE_TEMPLATE_ID`
   - `cloudfunctions/subscribe/index.js` 的 `TEMPLATE_ID`
5. **定时器**：`config.json` 已配置每日 08:00 触发 `send`，需在云开发控制台确认触发器已启用。

## 9. 注意事项（项目级）

1. **密钥安全**：`cloudfunctions/subscribe/index.js` 中 `APPSECRET` 为明文硬编码，存在泄露风险，建议改为云开发环境变量或密钥管理能力托管。
2. **订阅授权前置**：`wx.requestSubscribeMessage` 需用户在前端主动触发，云函数无法替用户授权；当前在添加页/卡片上引导授权是合理的。
3. **农历转换精度**：依赖 `lunar.js`，闰月与边界日期建议补充单元测试。
4. **诗词数据版权**：内置数据集需注意来源授权，上线前确认合规。
5. **复制功能已移除**：为降低审核风险，`onCopy` 已删除，若需恢复请确保符合平台内容规范。
6. **可扩展性**：新增首页功能只需在 `pages/index/index.js` 的 `features` 数组追加 `{id,name,desc,icon,bg,url}`。
7. **汉字拼音字库**：内置小学常用字（按字频取最常用的 **3000 字**，按声母分为 24 组，含拼音/声调/释义/组词/部首/笔画），数据在 `utils/hanzi_data/common.js`，加载与测验逻辑在 `utils/hanzi.js`；扩展字库仅改数据文件（或重跑 `utils/hanzi_data/_gen/build.js`）即可。
